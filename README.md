# Merge Conflict Resolution Practice

In this project, I practiced creating, reading, and resolving Git merge conflicts manually.

## What I Did:
1. **Repository Initialization:** Created a new Git repository and added an initial `config.txt` file.
2. **Branch Divergence:** Created a new branch (`set-author`) and modified the `author` field, while simultaneously modifying the exact same line differently on the `main` branch.
3. **Conflict Triggering:** Attempted to merge `set-author` into `main`, triggering a merge conflict.
4. **Manual Resolution:** Inspected the conflict markers (`<<<<<<< HEAD`, `=======`, `>>>>>>>`), resolved the discrepancy manually in `config.txt`, verified no leftover markers remained using `grep`, and finalized the merge commit.
